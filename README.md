# TRAP WORLD

A pixel-art platform game prototype built with HTML, CSS and vanilla JavaScript Canvas.

## Play locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. No build step or package installation is required.

For the best local development experience, use VS Code with the Live Server extension.

## Controls
- **A / D** or **← / →**: Move
- **Space**, **W** or **↑**: Jump
- **R**: Restart from the latest checkpoint
- On touch devices, use the on-screen buttons.

## Deploy to GitHub Pages
1. Create a new public GitHub repository named `trap-world`.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your game URL will appear in the Pages settings.

## Current prototype
- One playable level, "The First Lie"
- Keyboard and touch controls
- Spikes, collapsing platforms and crushers
- Death counter, checkpoint and finish state
- Procedural sound effects
